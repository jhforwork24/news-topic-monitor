# 일간 예약 토큰 사용량 실측 기록

## token-usage-by-run-2026-10-13_10-31.csv

2026-10-13~10-31 평일 일간 예약 15회차의 회차별 토큰·비용 집계다. 기존 일간 예약 세션(같은 세션에서
예약 실행과 유지보수 대화를 함께 처리하던 방식)의 실행 기록에서 각 응답 완료 기록의 '직전 완료 이후
사용량'을 모아 더했다. 금액은 실행 기록에 표시된 목록가 환산(`costBasis: list`)이며 실제 청구액이 아니다.

- `run_*`: 정규 실행(예약 시작부터 그날 발행 확인까지). `maint_*`: 같은 날 유지보수 대화(사람이 시작한
  응답, 발행 뒤 PR 작업 등). 주말·월요일 유지보수는 직전 회차에 귀속했다.
- `run_total_tokens` = 입력 + 캐시 쓰기 + 캐시 읽기 + 출력. 편집·감사 서브에이전트 사용량은 포함된 것으로
  본다(근거: 서브에이전트 보고 이벤트의 증분 출력과 누적 비용 흐름이 일치. 단정은 아님).
- `notes`의 '추정': 10-13~10-22 구간 69건은 증분 값이 없어 누적 사용량의 차분으로 채웠다. 비용 흐름과는
  맞았지만 토큰 칸은 추정치로 읽는다. 10-24는 결과 기록이 없는 중단 턴의 1.77달러를 누적 차분으로 보충했다.
- 분류가 모호한 이벤트 8건은 `notes`에 표시했다. 10-13은 발행 확인 기록이 없어 종료 시각과 정규 비용이
  특히 불확실하다.
- 합계: 정규 493.16M 토큰·128.82달러, 유지보수 78.26달러, 총 207.08달러. 정규 실행 평균 8.59달러.
