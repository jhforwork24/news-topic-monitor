# YouTube API 이용·데이터 처리 고지

이 프로젝트의 MBC 수집 기능은 YouTube API Services를 사용한다. 이 기능을 활성화하는 운영자는
[YouTube 이용약관](https://www.youtube.com/t/terms),
[YouTube API Services 개발자 정책](https://developers.google.com/youtube/terms/developer-policies),
[Google 개인정보처리방침](https://policies.google.com/privacy)을 확인해야 한다. 제3자가 직접
사용하는 서비스로 배포할 경우 운영자는 이 고지를 상시 접근 가능하게 제공하고, 적용 법령과
YouTube 정책이 요구하는 이용 동의·연락·삭제 요청 절차를 별도로 마련해야 한다.

## 접근 범위와 목적

API 키만 사용하는 비인가 공개 데이터 요청으로 MBCNEWS 공식 채널의 다음 정보만 확인한다.

- 채널 ID와 업로드 playlist ID
- 영상 ID, 제목, 발행시각, 공개 watch URL
- 주제 판별에 필요한 320자 이내의 공개 설명

영상·음원·자막·썸네일·조회수 등 통계, 댓글, 이용자 계정정보, 로그인 토큰은 수집하지 않는다.
자료는 장애인권·노동·돌봄·빈곤 의제의 언론 모니터링을 위해서만 사용한다. 보고서의 관련성
판정과 자체 요약은 YouTube가 제공한 정보가 아니라 이 프로젝트의 편집·분류 결과임을 명시한다.
표시할 때 출처명은 `MBCNEWS (YouTube)`로 구분한다.

## 저장·갱신·삭제

- API가 제공한 현재 영상 메타데이터는 기사 본문과 분리한 최소 JSONL 레코드로 저장한다.
- 마지막 확인 후 28일이 지난 레코드는 문서화된 `videos.list`로 다시 확인한다.
- 갱신 성공 응답에 나타난 영상은 최신 제목·설명·발행시각으로 교체한다.
- 성공 응답에서 더는 반환되지 않은 정확한 영상 ID는 현재 JSONL·review 캐시에서 제거한다.
- 일일보고처럼 당시 날짜와 조사기간을 명확히 밝힌 산출물은 역사 자료로서 시점 맥락을 유지한다.
- API 키는 URL, 로그, health, 보고서, fixture와 저장 레코드에 기록하지 않는다.

수집 데이터의 제거 요청과 운영 문의 창구는 각 배포의 공개 `MONITOR_CONTACT` 값으로 고지해야
한다. 저장소 템플릿의 예시 주소를 실제 연락처로 간주해서는 안 된다. 삭제 요청은 YouTube 원본
삭제가 아니라 이 모니터가 보관한 데이터의 삭제에만 적용된다.
